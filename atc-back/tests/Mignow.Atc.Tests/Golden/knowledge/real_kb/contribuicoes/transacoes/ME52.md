### C-ME52-001

**Padrão:** Contribuição (IA confirmada)  
**Ocorrências:** 1  
**Registrado em:** 2026-10-22  
**Problema:** Functionality unavailable (nota 1803189): BDC SAPMM06B + CALL TRANSACTION ME52  
**Substitui:** S00068, S00795, S02508  

**Problema (código original)**

```abap
* Linhas 60-63
    SELECT * FROM CDHDR WHERE OBJECTCLAS EQ 'BANF'
                          AND OBJECTID   EQ W-OBJECTID
                          AND TCODE      EQ 'ME52'
                          AND USERNAME   EQ SYST-UNAME.
* FORM ME52 - linhas 214-242
  REFRESH TAB_BDCDATA.
  PERFORM GEN_DYNPRO USING:
      'X'  'sapmm06b'              '0105',
      ' '  'eban-banfn'             P-BANFN,
      ' '  'bdc_okcode'            '/00'.
  SELECT * FROM EBAN WHERE BANFN EQ P-BANFN
                       AND LOEKZ EQ SPACE
    ORDER BY PRIMARY KEY.
    PERFORM GEN_DYNPRO USING:
        'X'  'SAPMM06b'              '0106',
        ' '  'rm06b-bnfpo'            EBAN-BNFPO,
        ' '  'bdc_okcode'            '/00',
        'X'  'SAPMM06b'              '0106',
        ' '  'bdc_cursor'            'eban-matnr(01)',
        ' '  'bdc_okcode'            '=DETA',
        'X'  'SAPMM06b'              '0102',
        ' '  'eban-ekgrp'             P-EKGRP,
        ' '  'eban-ekorg'             P-EKORG,
        ' '  'eban-lifnr'             P-LIFNR.
    PERFORM GEN_DYNPRO USING:
        ' '  'bdc_okcode'            '/00'.
  ENDSELECT.
  PERFORM GEN_DYNPRO USING:
        'X'  'SAPMM06b'              '0106',
        ' '  'bdc_okcode'            '=BU'.
  CALL TRANSACTION 'ME52' USING TAB_BDCDATA
                           MODE 'N'
                         UPDATE 'S'.
  WRITE:/ 'DA', P-BANFN, 'Code retour call transaction', SY-SUBRC.
```

**Solução (código novo)**

```abap
* Linhas 60-63
    SELECT * FROM CDHDR WHERE OBJECTCLAS EQ 'BANF'
                          AND OBJECTID   EQ W-OBJECTID
                          AND TCODE      IN ('ME52', 'ME52N', SYST-TCODE)
                          AND USERNAME   EQ SYST-UNAME.
* FORM ME52 - linhas 214-242
  DATA: LT_ITEM   TYPE STANDARD TABLE OF BAPIMEREQITEMIMP,
        LT_ITEMX  TYPE STANDARD TABLE OF BAPIMEREQITEMX,
        LT_RETURN TYPE STANDARD TABLE OF BAPIRET2,
        LS_ITEM   TYPE BAPIMEREQITEMIMP,
        LS_ITEMX  TYPE BAPIMEREQITEMX,
        LV_SUBRC  TYPE SYST-SUBRC.

  SELECT * FROM EBAN WHERE BANFN EQ P-BANFN
                       AND LOEKZ EQ SPACE
    ORDER BY PRIMARY KEY.
    CLEAR: LS_ITEM, LS_ITEMX.
    LS_ITEM-PREQ_ITEM   = EBAN-BNFPO.
    LS_ITEM-PUR_GROUP   = P-EKGRP.
    LS_ITEM-PURCH_ORG   = P-EKORG.
    LS_ITEM-DES_VENDOR  = P-LIFNR.
    LS_ITEMX-PREQ_ITEM  = EBAN-BNFPO.
    LS_ITEMX-PREQ_ITEMX = 'X'.
    LS_ITEMX-PUR_GROUP  = 'X'.
    LS_ITEMX-PURCH_ORG  = 'X'.
    LS_ITEMX-DES_VENDOR = 'X'.
    APPEND: LS_ITEM TO LT_ITEM, LS_ITEMX TO LT_ITEMX.
  ENDSELECT.
  CHECK LT_ITEM IS NOT INITIAL.

  CALL FUNCTION 'BAPI_PR_CHANGE'
    EXPORTING
      NUMBER  = P-BANFN
    TABLES
      RETURN  = LT_RETURN
      PRITEM  = LT_ITEM
      PRITEMX = LT_ITEMX.

  LOOP AT LT_RETURN TRANSPORTING NO FIELDS WHERE TYPE CA 'EAX'.
    EXIT.
  ENDLOOP.
  IF SY-SUBRC EQ 0.
    LV_SUBRC = 4.
    CALL FUNCTION 'BAPI_TRANSACTION_ROLLBACK'.
  ELSE.
    CLEAR LV_SUBRC.
    CALL FUNCTION 'BAPI_TRANSACTION_COMMIT'
      EXPORTING
        WAIT = 'X'.
  ENDIF.
  WRITE:/ 'DA', P-BANFN, 'Code retour BAPI_PR_CHANGE', LV_SUBRC.
```

### C-ME52-002

**Padrão:** Contribuição (IA confirmada)  
**Ocorrências:** 1  
**Registrado em:** 2026-10-22  
**Problema:** Batch input da ME52 (SAPMM06B 0105/0106, =MALL/=DL/=BU) executado na ME52N: telas não correspondem; eliminar itens da requisição via BAPI_REQUISITION_DELETE  

**Problema (código original)**

```abap
    REFRESH bdcdata.
* 1ª Tela
    PERFORM bdc_dynpro USING  'SAPMM06B'          '0105'.
    PERFORM bdc_field USING:  'BDC_OKCODE'        '/00',
                              'BDC_CURSOR'        'EBAN-BANFN',
                              'EBAN-BANFN'        itab_reserva-reserva.

* 2ª Tela
    PERFORM bdc_dynpro USING  'SAPMM06B'          '0106'.
    PERFORM bdc_field USING:  'BDC_OKCODE'        '=MALL',
                              'BDC_CURSOR'        'RM06B-BNFPO'.

* 3ª Tela
    PERFORM bdc_dynpro USING  'SAPMM06B'          '0106'.
    PERFORM bdc_field USING:  'BDC_OKCODE'        '=DL',
                              'BDC_CURSOR'        'RM06B-BNFPO'.

* 4ª Tela
    PERFORM bdc_dynpro USING  'SAPMM06B'          '0106'.
    PERFORM bdc_field USING:  'BDC_OKCODE'        '=BU',
                              'BDC_CURSOR'        'EBAN-BNFPO(01)'.

* CHAMADA DA TRANSAÇÃO
*>>> S/4 MIGRATION MIG-NOW - START OF DELETION - 05.06.2026 09:23:12 - AC
*    CALL TRANSACTION 'ME52' USING bdcdata
*<<< S/4 MIGRATION MIG-NOW - END OF DELETION - 05.06.2026 09:23:12 - AC
*>>> S/4 MIGRATION MIG-NOW - START OF INSERTION - 05.06.2026 09:23:12 - AC
    CALL TRANSACTION 'ME52N' USING bdcdata
*<<< S/4 MIGRATION MIG-NOW - END OF INSERTION - 05.06.2026 09:23:12 - AC
                            MODE v_mode
                            UPDATE 'S'
                            MESSAGES INTO t_bdcmsgcoll.
```

**Solução (código novo)**

```abap
    DATA: lv_banfn_del TYPE eban-banfn,
          lt_pr_del    TYPE STANDARD TABLE OF bapieband,
          ls_pr_del    TYPE bapieband,
          lt_pr_ret    TYPE STANDARD TABLE OF bapireturn,
          ls_pr_ret    TYPE bapireturn,
          lv_pr_msg    TYPE string.

* Elimina todos os itens da requisição via BAPI (substitui o batch input da ME52)
    lv_banfn_del = itab_reserva-reserva.
    CLEAR: lt_pr_del, lt_pr_ret, ls_pr_ret.
    REFRESH t_bdcmsgcoll.
    SELECT bnfpo FROM eban INTO ls_pr_del-preq_item
      WHERE banfn = lv_banfn_del
        AND loekz = space.
      ls_pr_del-delete_ind = 'X'.
      APPEND ls_pr_del TO lt_pr_del.
    ENDSELECT.

    CALL FUNCTION 'BAPI_REQUISITION_DELETE'
      EXPORTING
        number                      = lv_banfn_del
      TABLES
        requisition_items_to_delete = lt_pr_del
        return                      = lt_pr_ret.

* Mensagens no formato do batch input (usadas por monta_log/f_export_erro)
    LOOP AT lt_pr_ret INTO ls_pr_ret WHERE type CA 'EA'.
      EXIT.
    ENDLOOP.
    IF sy-subrc = 0.
      CLEAR t_bdcmsgcoll.
      t_bdcmsgcoll-msgtyp = 'E'.
      t_bdcmsgcoll-msgid  = ls_pr_ret-code(2).
      t_bdcmsgcoll-msgnr  = ls_pr_ret-code+2(3).
      t_bdcmsgcoll-msgv1  = ls_pr_ret-message_v1.
      t_bdcmsgcoll-msgv2  = ls_pr_ret-message_v2.
      t_bdcmsgcoll-msgv3  = ls_pr_ret-message_v3.
      t_bdcmsgcoll-msgv4  = ls_pr_ret-message_v4.
      APPEND t_bdcmsgcoll.
      MESSAGE ID ls_pr_ret-code(2) TYPE 'E' NUMBER ls_pr_ret-code+2(3)
              WITH ls_pr_ret-message_v1 ls_pr_ret-message_v2
                   ls_pr_ret-message_v3 ls_pr_ret-message_v4
              INTO lv_pr_msg.
    ELSE.
      MESSAGE ID 'W5' TYPE 'S' NUMBER '041' WITH lv_banfn_del INTO lv_pr_msg.
    ENDIF.
```

```abap

        lt_pr_item   TYPE STANDARD TABLE OF bapimereqitemimp,
```

### C-ME52-004

**Padrão:** Contribuição (IA confirmada)  
**Ocorrências:** 1  
**Registrado em:** 2026-10-22  
**Problema:** Batch input da ME52 (cancelar requisição) executado na ME52N com verificação da mensagem 06/403: eliminar via BAPI_REQUISITION_DELETE e converter o RETURN em t_bdcmsgcoll (sucesso W5/041)  

**Problema (código original)**

```abap
  PERFORM bdc_dynpro USING  'SAPMM06B'              '105'.
  PERFORM bdc_field  USING: 'BDC_OKCODE'            '/00',
                            'EBAN-BANFN'            p_nro.

  PERFORM bdc_dynpro USING  'SAPMM06B'              '106'.
  PERFORM bdc_field  USING: 'BDC_OKCODE'            '=DL',
                            'RM06B-TCSELFLAG(01)'   'X'.

  PERFORM bdc_dynpro USING  'SAPMM06B'              '106'.
  PERFORM bdc_field  USING: 'BDC_OKCODE'            '=BU'.

  REFRESH: t_bdcmsgcoll.
*>>> S/4 MIGRATION MIG-NOW - START OF DELETION - 05.06.2026 09:23:12 - AC
*  CALL TRANSACTION 'ME52' USING bdcdata
*<<< S/4 MIGRATION MIG-NOW - END OF DELETION - 05.06.2026 09:23:12 - AC
*>>> S/4 MIGRATION MIG-NOW - START OF INSERTION - 05.06.2026 09:23:12 - AC
  CALL TRANSACTION 'ME52N' USING bdcdata
*<<< S/4 MIGRATION MIG-NOW - END OF INSERTION - 05.06.2026 09:23:12 - AC
                          MODE g_mode
                          UPDATE 'S'
                          MESSAGES INTO t_bdcmsgcoll.
  IF sy-subrc = 0.
*   buscar nas mensagens
    SORT t_bdcmsgcoll BY msgnr.
    READ TABLE t_bdcmsgcoll WITH KEY msgnr = '403'.
*   grava log de sucesso
    IF sy-subrc = 0.
      PERFORM f_grava_message USING '2'.
    ENDIF.
  ELSE.
    READ TABLE t_bdcmsgcoll WITH KEY msgtyp = 'E'.
    IF sy-subrc = 0.
      PERFORM f_grava_message USING '2E'.
    ENDIF.

  ENDIF.
```

**Solução (código novo)**

```abap
  DATA: lv_banfn_del TYPE eban-banfn,
        lt_pr_del    TYPE STANDARD TABLE OF bapieband,
        ls_pr_del    TYPE bapieband,
        lt_pr_ret    TYPE STANDARD TABLE OF bapireturn,
        ls_pr_ret    TYPE bapireturn.

* Elimina os itens da requisição via BAPI (substitui o batch input da ME52)
  lv_banfn_del = p_nro.
  REFRESH t_bdcmsgcoll.
  SELECT bnfpo FROM eban INTO ls_pr_del-preq_item
    WHERE banfn = lv_banfn_del
      AND loekz = space.
    ls_pr_del-delete_ind = 'X'.
    APPEND ls_pr_del TO lt_pr_del.
  ENDSELECT.

  CALL FUNCTION 'BAPI_REQUISITION_DELETE'
    EXPORTING
      number                      = lv_banfn_del
    TABLES
      requisition_items_to_delete = lt_pr_del
      return                      = lt_pr_ret.

* Mensagens da BAPI no formato do batch input (usadas por f_grava_message)
  LOOP AT lt_pr_ret INTO ls_pr_ret.
    CLEAR t_bdcmsgcoll.
    t_bdcmsgcoll-msgtyp = ls_pr_ret-type.
    IF ls_pr_ret-type = 'A'.
      t_bdcmsgcoll-msgtyp = 'E'.
    ENDIF.
    t_bdcmsgcoll-msgid = ls_pr_ret-code(2).
    t_bdcmsgcoll-msgnr = ls_pr_ret-code+2(3).
    t_bdcmsgcoll-msgv1 = ls_pr_ret-message_v1.
    t_bdcmsgcoll-msgv2 = ls_pr_ret-message_v2.
    t_bdcmsgcoll-msgv3 = ls_pr_ret-message_v3.
    t_bdcmsgcoll-msgv4 = ls_pr_ret-message_v4.
    APPEND t_bdcmsgcoll.
  ENDLOOP.

  READ TABLE t_bdcmsgcoll WITH KEY msgtyp = 'E'.
  IF sy-subrc <> 0.
*   grava log de sucesso (W5 041: requisição modificada)
    READ TABLE t_bdcmsgcoll WITH KEY msgid = 'W5' msgnr = '041'.
    IF sy-subrc = 0.
      PERFORM f_grava_message USING '2'.
    ENDIF.
  ELSE.
    PERFORM f_grava_message USING '2E'.
  ENDIF.
```
