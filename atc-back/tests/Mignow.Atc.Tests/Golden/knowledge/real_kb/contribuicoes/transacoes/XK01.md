### C-XK01-001

**Padrão:** Contribuição (IA confirmada)  
**Ocorrências:** 1  
**Registrado em:** 2026-10-24  
**Problema:** CALL TRANSACTION XK01 para ampliar fornecedor existente para nova empresa (RF02K-LIFNR preenchido): CL_MD_BP_MAINTAIN company task I (LFB1 telas 0210/0215 + LFZA) via ZF_BP_FORN_EMPRESA; nao usar ZCL_MIGBP (criaria outro BP). Ativado no EC2 (ZINT)  

**Problema (código original)**

```abap
      call transaction c_trans_xk01 using t_bdc
        mode v_mode  update 'S'.
```

**Solução (código novo)**

```abap
*     XK01 indisponivel no S/4: amplia o fornecedor (BP) para a empresa
      perform zf_xk01_bp_empresa using w_dados t_emp.
*&---------------------------------------------------------------------*
*&      Form  ZF_XK01_BP_EMPRESA
*&---------------------------------------------------------------------*
* XK01 indisponivel no S/4: amplia o fornecedor existente para a
* empresa PS_EMP-BUKRS no BP via CVI (telas 0210/0215 e 1130)
*----------------------------------------------------------------------*
FORM zf_xk01_bp_empresa USING ps_dados TYPE ty_dados
                              ps_emp   TYPE ty_emp.

  DATA: ls_data  TYPE cvis_ei_extern,
        lv_chave TYPE char15,
        lv_ok    TYPE abap_bool.

  PERFORM zf_bp_forn_header USING ps_dados-lifnr CHANGING ls_data lv_ok.
  CHECK lv_ok = abap_true.

  PERFORM zf_bp_forn_empresa USING    ps_dados ps_emp 'I'
                             CHANGING ls_data lv_ok.
  CHECK lv_ok = abap_true.

  CONCATENATE ls_data-vendor-header-object_instance-lifnr ps_emp-bukrs
    INTO lv_chave SEPARATED BY space.
  PERFORM zf_bp_gravar USING ls_data 'Fornecedor ampliado para empresa (BP):'
                             lv_chave.

ENDFORM.                    " ZF_XK01_BP_EMPRESA
*&---------------------------------------------------------------------*
*&      Form  ZF_XK06_BP_ELIM
*&---------------------------------------------------------------------*
* XK06 indisponivel no S/4: marca (ou desmarca) a eliminacao e o
* bloqueio de eliminacao do fornecedor (LFA1-LOEVM/NODEL) no BP
*----------------------------------------------------------------------*
FORM zf_xk06_bp_elim USING pv_lifnr TYPE c
                           pv_flag  TYPE c.

  DATA: ls_data TYPE cvis_ei_extern,
        lv_ok   TYPE abap_bool.

  PERFORM zf_bp_forn_header USING pv_lifnr CHANGING ls_data lv_ok.
  CHECK lv_ok = abap_true.

  ls_data-vendor-central_data-central-data-loevm  = pv_flag.
  ls_data-vendor-central_data-central-data-nodel  = pv_flag.
  ls_data-vendor-central_data-central-datax-loevm = abap_true.
  ls_data-vendor-central_data-central-datax-nodel = abap_true.

  PERFORM zf_bp_gravar USING ls_data 'Marca de eliminacao gravada (BP):'
                             ls_data-vendor-header-object_instance-lifnr.

ENDFORM.                    " ZF_XK06_BP_ELIM
```

### C-XK01-002

**Padrão:** Contribuição (IA confirmada)  
**Ocorrências:** 1  
**Registrado em:** 2026-10-24  
**Problema:** CALL TRANSACTION XK01/XK02 tela 0310 (LFM1) para incluir/alterar organizacao de compras de fornecedor existente: CL_MD_BP_MAINTAIN purchasing task I/U com datax (WAERS, ZTERM, KALSK, VERKF, TELF1, WEBRE, KZAUT, LEBRE, BSTAE). Ativado no EC2 (ZINT)  

**Problema (código original)**

```abap
    CALL TRANSACTION 'XK01' USING t_bdc MODE v_mode UPDATE 'S'.
```

**Solução (código novo)**

```abap
*   XK01 indisponivel no S/4: inclui a organizacao de compras no BP
    PERFORM zf_bp_forn_compras USING wa_org_comp 'I'.
*   XK02 indisponivel no S/4: modifica a organizacao de compras no BP
    PERFORM zf_bp_forn_compras USING wa_org_comp 'U'.
*&---------------------------------------------------------------------*
*&      Form  ZF_BP_FORN_COMPRAS
*&---------------------------------------------------------------------*
* XK01/XK02 indisponiveis no S/4: dados de compras do fornecedor (LFM1,
* tela 0310) no BP via CVI. PV_TASK 'I' inclui a organizacao de
* compras, 'U' modifica
*----------------------------------------------------------------------*
FORM zf_bp_forn_compras USING ps_org  TYPE zmme_interforn_org_comp
                              pv_task TYPE c.

  DATA: ls_data     TYPE cvis_ei_extern,
        ls_purchase TYPE vmds_ei_purchasing,
        lv_chave    TYPE char15,
        lv_ok       TYPE abap_bool.

  PERFORM zf_bp_forn_header USING ps_org-lifnr CHANGING ls_data lv_ok.
  CHECK lv_ok = abap_true.

  ls_purchase-task           = pv_task.
  ls_purchase-data_key-ekorg = ps_org-ekorg.
  ls_purchase-data-waers     = ps_org-waers.
  ls_purchase-data-zterm     = ps_org-zterm.
  ls_purchase-data-kalsk     = ps_org-kalsk.
  ls_purchase-data-verkf     = ps_org-verkf.
  ls_purchase-data-telf1     = ps_org-telf1.
  ls_purchase-data-webre     = ps_org-webre.
  ls_purchase-data-kzaut     = ps_org-kzaut.
  ls_purchase-data-lebre     = ps_org-lebre.
  ls_purchase-data-bstae     = ps_org-bstae.
  ls_purchase-datax-waers    = abap_true.
  ls_purchase-datax-zterm    = abap_true.
  ls_purchase-datax-kalsk    = abap_true.
  ls_purchase-datax-verkf    = abap_true.
  ls_purchase-datax-telf1    = abap_true.
  ls_purchase-datax-webre    = abap_true.
  ls_purchase-datax-kzaut    = abap_true.
  ls_purchase-datax-lebre    = abap_true.
  ls_purchase-datax-bstae    = abap_true.
  APPEND ls_purchase TO ls_data-vendor-purchasing_data-purchasing.

  CONCATENATE ls_data-vendor-header-object_instance-lifnr ps_org-ekorg
    INTO lv_chave SEPARATED BY space.
  PERFORM zf_bp_gravar USING ls_data 'Org. de compras gravada (BP):' lv_chave.

ENDFORM.                    " ZF_BP_FORN_COMPRAS
```

### C-XK01-003

**Padrão:** Contribuição (IA confirmada)  
**Ocorrências:** 1  
**Registrado em:** 2026-10-24  
**Problema:** Semantically incompatible change of existing functionality / Functionality unavailable (XK01 criacao de fornecedor por batch input com numero externo)  

**Problema (código original)**

```abap
    CALL TRANSACTION 'XK01' USING t_bdc
      MODE v_mode  UPDATE 'S'.
```

**Solução (código novo)**

```abap
*   XK01 indisponivel no S/4: cria o fornecedor (BP) com os dados
*   gerais das telas 0111/0120 e o numero da interface
    PERFORM zf_xk01_bp_criar USING w_dados.

*&---------------------------------------------------------------------*
*&      Form  ZF_XK01_BP_CRIAR
*&---------------------------------------------------------------------*
* XK01 indisponivel no S/4: cria o BP do fornecedor via CVI com os
* dados gerais das telas 0111 (nome/endereco/comunicacao) e 0120
* (dados fiscais e de controle). BP com numero interno; fornecedor com
* o numero da interface (RF02K-LIFNR); agrupamento pela TBC001 (KTOKK)
*----------------------------------------------------------------------*
FORM zf_xk01_bp_criar USING ps_dados TYPE ty_dados.

  CONSTANTS: lc_valid_to TYPE d VALUE '99991231'.

  DATA: ls_data    TYPE cvis_ei_extern,
        ls_role    TYPE bus_ei_bupa_roles,
        ls_address TYPE bus_ei_bupa_address,
        lt_grupo   TYPE STANDARD TABLE OF bu_group WITH DEFAULT KEY,
        lt_role    TYPE STANDARD TABLE OF bu_role WITH DEFAULT KEY,
        lv_role    TYPE bu_role,
        lv_lifnr   TYPE lifnr,
        lv_kunnr   TYPE kunnr,
        lv_adrnr   TYPE adrnr,
        lv_partner TYPE bu_partner,
        lv_msg     TYPE string.

  lv_lifnr = ps_dados-lifnr.
  PERFORM z_format_lifnr CHANGING lv_lifnr.

* Agrupamento do BP pelo grupo de contas do fornecedor (TBC001)
  SELECT bu_group FROM tbc001
    WHERE ktokk = @ps_dados-ktokk
    INTO TABLE @lt_grupo.
  IF lines( lt_grupo ) <> 1.
    MESSAGE e398(00) WITH 'Agrupamento BP (TBC001) nao unico/ausente'
                          'para o grupo de contas' ps_dados-ktokk
      INTO lv_msg.
    RETURN.
  ENDIF.

  ls_data-partner-header-object_task = 'I'.
  TRY.
      ls_data-partner-header-object_instance-bpartnerguid =
        cl_system_uuid=>create_uuid_x16_static( ).
    CATCH cx_uuid_error.
      MESSAGE e398(00) WITH 'Erro ao gerar GUID do BP:' lv_lifnr INTO lv_msg.
      RETURN.
  ENDTRY.
  ls_data-partner-central_data-common-data-bp_control-category = '2'.
  ls_data-partner-central_data-common-data-bp_control-grouping = lt_grupo[ 1 ].

* Tela 0111: nome e termo de pesquisa
  ls_data-partner-central_data-common-data-bp_organization-name1  = ps_dados-name1.
  ls_data-partner-central_data-common-data-bp_organization-name2  = ps_dados-name2.
  ls_data-partner-central_data-common-datax-bp_organization-name1 = abap_true.
  ls_data-partner-central_data-common-datax-bp_organization-name2 = abap_true.
  ls_data-partner-central_data-common-data-bp_centraldata-searchterm1  = ps_dados-sort1.
  ls_data-partner-central_data-common-datax-bp_centraldata-searchterm1 = abap_true.

* Papeis de fornecedor (geral e compras)
  APPEND 'FLVN00' TO lt_role.
  APPEND 'FLVN01' TO lt_role.
  LOOP AT lt_role INTO lv_role.
    CLEAR ls_role.
    ls_role-task             = 'I'.
    ls_role-data_key         = lv_role.
    ls_role-data-valid_from  = sy-datum.
    ls_role-data-valid_to    = lc_valid_to.
    ls_role-datax-valid_from = abap_true.
    ls_role-datax-valid_to   = abap_true.
    APPEND ls_role TO ls_data-partner-central_data-role-roles.
  ENDLOOP.

* Tela 0111: endereco e comunicacao (fax = telefone, como o batch input)
  ls_address-task                         = 'I'.
  ls_address-data-postal-data-street      = ps_dados-street.
  ls_address-data-postal-data-house_no    = ps_dados-house_num1.
  ls_address-data-postal-data-str_suppl3  = ps_dados-str_suppl3.
  ls_address-data-postal-data-district    = ps_dados-city2.
  ls_address-data-postal-data-postl_cod1  = ps_dados-post_code1.
  ls_address-data-postal-data-city        = ps_dados-city1.
  ls_address-data-postal-data-country     = ps_dados-country.
  ls_address-data-postal-data-region      = ps_dados-region.
  ls_address-data-postal-data-taxjurcode  = ps_dados-taxjurcode.
  ls_address-data-postal-data-langu       = ps_dados-langu.
  ls_address-data-postal-datax-street     = abap_true.
  ls_address-data-postal-datax-house_no   = abap_true.
  ls_address-data-postal-datax-str_suppl3 = abap_true.
  ls_address-data-postal-datax-district   = abap_true.
  ls_address-data-postal-datax-postl_cod1 = abap_true.
  ls_address-data-postal-datax-city       = abap_true.
  ls_address-data-postal-datax-country    = abap_true.
  ls_address-data-postal-datax-region     = abap_true.
  ls_address-data-postal-datax-taxjurcode = abap_true.
  ls_address-data-postal-datax-langu      = abap_true.
  PERFORM zf_bp_comunicacao USING    lv_adrnr ps_dados-country
                                     ps_dados-tel_number ps_dados-mob_number
                                     ps_dados-tel_number
                            CHANGING ls_address-data-communication.
  APPEND ls_address TO ls_data-partner-central_data-address-addresses.

* Tela 0120: dados fiscais (numeros fiscais no BP) e dados de controle
  PERFORM zf_bp_nr_fiscal USING    lv_partner '1234' ps_dados-country ps_dados-stcdt
                                   ps_dados-stcd1 ps_dados-stcd2
                                   ps_dados-stcd3 ps_dados-stcd4
                          CHANGING ls_data-partner-central_data-taxnumber.
  ls_data-partner-central_data-taxnumber-common-data-nat_person  = ps_dados-stkzn.
  ls_data-partner-central_data-taxnumber-common-datax-nat_person = abap_true.

  ls_data-vendor-header-object_task           = 'I'.
  ls_data-vendor-header-object_instance-lifnr = lv_lifnr.
  ls_data-ensure_create-create_vendor         = abap_true.
  lv_kunnr = ps_dados-kunnr.
  IF lv_kunnr IS NOT INITIAL.
    PERFORM z_format_lifnr CHANGING lv_kunnr.
  ENDIF.
  ls_data-vendor-central_data-central-data-ktokk      = ps_dados-ktokk.
  ls_data-vendor-central_data-central-data-kunnr      = lv_kunnr.
  ls_data-vendor-central_data-central-data-vbund      = ps_dados-vbund.
  ls_data-vendor-central_data-central-data-brsch      = ps_dados-brsch.
  ls_data-vendor-central_data-central-data-j_1kftind  = ps_dados-j_1kftind.
  ls_data-vendor-central_data-central-data-stcdt      = ps_dados-stcdt.
  ls_data-vendor-central_data-central-data-fityp      = ps_dados-fityp.
  ls_data-vendor-central_data-central-datax-ktokk     = abap_true.
  ls_data-vendor-central_data-central-datax-kunnr     = abap_true.
  ls_data-vendor-central_data-central-datax-vbund     = abap_true.
  ls_data-vendor-central_data-central-datax-brsch     = abap_true.
  ls_data-vendor-central_data-central-datax-j_1kftind = abap_true.
  ls_data-vendor-central_data-central-datax-stcdt     = abap_true.
  ls_data-vendor-central_data-central-datax-fityp     = abap_true.

  PERFORM zf_bp_gravar USING ls_data 'Fornecedor criado (BP):' lv_lifnr.

ENDFORM.                    " ZF_XK01_BP_CRIAR
```
