### C-FD01-001

**Padrão:** Contribuição (IA confirmada)  
**Ocorrências:** 1  
**Registrado em:** 2026-10-22  
**Problema:** FD01 chamado de forma interativa (sem BDC) para criar cliente -> CALL TRANSACTION 'BP' WITH AUTHORITY-CHECK (CVI sincroniza KNA1/KNB1); parametros KUN/BUK nao pre-preenchem o BP  

**Problema (código original)**

```abap
  CALL TRANSACTION 'FD01'.
```

**Solução (código novo)**

```abap
* S/4HANA : création client via Business Partner (rôle FLCU00 pour la société)
  CALL TRANSACTION 'BP' WITH AUTHORITY-CHECK.
```

### C-FD01-002

**Padrão:** Contribuição (IA confirmada)  
**Ocorrências:** 1  
**Registrado em:** 2026-10-22  
**Problema:** FD01 interativo para criar/estender cliente -> navegacao direta ao BP (cl_bupa_dialog_joel=>start_with_navigation), parceiro via CVI_CUST_LINK, papel FLCU00, atividade 02 se existe senao 01  

**Problema (código original)**

```abap
  CALL TRANSACTION 'FD01'.
```

**Solução (código novo)**

```abap
* S/4HANA : création/extension client via Business Partner (rôle FLCU00)
  DATA: lv_partner TYPE bu_partner,
        ls_role    TYPE bus_roles.
  SELECT SINGLE b~partner FROM cvi_cust_link AS l
         INNER JOIN but000 AS b ON b~partner_guid = l~partner_guid
         INTO lv_partner
         WHERE l~customer = *kna1-kunnr.
  DATA(lo_request) = NEW cl_bupa_navigation_request( ).
  IF sy-subrc = 0.
    lo_request->set_partner_number( lv_partner ).
    lo_request->set_bupa_activity( '02' ).   " Modifier
  ELSE.
    lo_request->set_bupa_activity( '01' ).   " Créer
  ENDIF.
  lo_request->set_maintenance_id( 'B' ).
  ls_role-role = 'FLCU00'.
  lo_request->set_bupa_partner_role( ls_role ).
  DATA(lo_options) = NEW cl_bupa_dialog_joel_options( ).
  lo_options->set_locator_visible( space ).
  CALL METHOD cl_bupa_dialog_joel=>start_with_navigation
    EXPORTING
      iv_request              = lo_request
      iv_options              = lo_options
      iv_in_new_internal_mode = abap_true
    EXCEPTIONS
      already_started         = 1
      not_allowed             = 2
      OTHERS                  = 3.
```
