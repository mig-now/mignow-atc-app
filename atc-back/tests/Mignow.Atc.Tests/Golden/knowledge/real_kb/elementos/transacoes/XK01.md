### S01097

**Padrão:** [Não classificado](../../padroes/P99_nao_classificado.md)  
**Ocorrências:** 2  
**Removido:** `XK01` (Transação)  
**Incluído:** `ZCL_MIGBP` (Classe/Interface), `BDCDATA_TAB` (Tipo (DDIC)), `TAB_BDCMSGCOLL` (Tipo (DDIC))  

**Problema (código original)**

```abap
    CALL TRANSACTION 'XK01'
                     USING it_bdcdata
                     MODE p_modo
                     UPDATE 'S'
                     MESSAGES INTO it_mensagem.
```

**Solução (código novo)**

```abap
DATA: lt_bdc    TYPE bdcdata_tab,
      lt_bdcmsg TYPE tab_bdcmsgcoll,
      lo_migbp  TYPE REF TO zcl_migbp.

lt_bdc = CONV #( it_bdcdata[] ).

CREATE OBJECT lo_migbp
  EXPORTING
    im_test    = abap_false
    im_tcode   = 'BP'
    it_bdcdata = lt_bdc.

CALL METHOD lo_migbp->mt_bp_process_old_shdb(
  CHANGING
    ct_bdcmsg = lt_bdcmsg ).

CALL METHOD lo_migbp->mt_bp_process_data(
  CHANGING
    ct_bdcmsg = lt_bdcmsg ).

it_mensagem[] = CONV #( lt_bdcmsg[] ).
```

### S01098

**Padrão:** [Não classificado](../../padroes/P99_nao_classificado.md)  
**Ocorrências:** 2  
**Removido:** `XK01` (Transação)  
**Incluído:** `ZCL_MIGBP` (Classe/Interface), `BDCDATA_TAB` (Tipo (DDIC)), `TAB_BDCMSGCOLL` (Tipo (DDIC))  

**Problema (código original)**

```abap
  CALL TRANSACTION 'XK01'
                   USING it_bdcdata
                   OPTIONS FROM  wa_params
                   MESSAGES INTO it_mensagem.
```

**Solução (código novo)**

```abap
DATA: lt_bdc_aux    TYPE bdcdata_tab,
      lt_bdcmsg_aux TYPE tab_bdcmsgcoll,
      lo_migbp_aux  TYPE REF TO zcl_migbp.

DATA: ls_bdc_destino   LIKE LINE OF lt_bdc_aux,
      ls_mensagem_local LIKE LINE OF it_mensagem.

REFRESH lt_bdc_aux.
LOOP AT it_bdcdata INTO DATA(ls_bdc_origem).
  CLEAR ls_bdc_destino.
  MOVE-CORRESPONDING ls_bdc_origem TO ls_bdc_destino.
  APPEND ls_bdc_destino TO lt_bdc_aux.
ENDLOOP.

CREATE OBJECT lo_migbp_aux
  EXPORTING
    im_test    = abap_false
    im_tcode   = 'BP'
    it_bdcdata = lt_bdc_aux.

CALL METHOD lo_migbp_aux->mt_bp_process_old_shdb(
  CHANGING
    ct_bdcmsg = lt_bdcmsg_aux ).

CALL METHOD lo_migbp_aux->mt_bp_process_data(
  CHANGING
    ct_bdcmsg = lt_bdcmsg_aux ).

REFRESH it_mensagem.
LOOP AT lt_bdcmsg_aux INTO DATA(ls_bdcmsg_linha).
  CLEAR ls_mensagem_local.
  MOVE-CORRESPONDING ls_bdcmsg_linha TO ls_mensagem_local.
  APPEND ls_mensagem_local TO it_mensagem.
ENDLOOP.
```


```abap
DATA: lt_bdc_aux    TYPE bdcdata_tab,
      lt_bdcmsg_aux TYPE tab_bdcmsgcoll,
      lo_migbp_aux  TYPE REF TO zcl_migbp.

  EXPORTING
    im_test    = abap_false
```
